# Dashboard UI

This app lets users interact with their accounts and make/update orders and their info.

## How to run locally

You can start the app locally with the following commands:

- `pnpm install`
- `pnpm dev`

It should run on `http://localhost:5173/`.

## Project structure

The `components` folder contains smaller, reusable elements like search bars, common styled components, the navbar, and the header.

The `pages` folder contains the main modules that make up full pages, such as the user info and user actions pages.
